# Skybreak
Original single-player browser-native 3D building/shooting prototype. Static site; serve dist/ over HTTP. No build step. Three.js 0.170.0 is vendored under its MIT license. No Fortnite assets, Carbon code, or Magnesium code are included.

Controls: WASD, mouse aim, Space jump, Shift sprint, 1 rifle, 2 wall, 3 ramp, R rotate, left click use, Escape pause. Eight targets, 300 wood, 10 wood per structure. Desktop keyboard/mouse required. Multiplayer, mobile controls, editing, damage, persistence, and backend integration are not implemented.

For GitHub Pages, publish the contents of dist/. Keep vendor/THREE-LICENSE.txt.
